Blockchain-projects

I'm learning blockchain by building small projects in Python, one at a
time. Each project has its own folder with the code, a README and
screenshots.

## Projects

1. [Turbine alarm hash chain](01-turbine-alarm-hashchain): a tamper-evident
   alarm log for a turbine. If anyone edits or deletes an entry, the
   chain catches it.
2. [Merkle tree](02-merkle-tree): check one record out of many using a
   short proof, without going through everything.
3. [Proof of work](03-proof-of-work): a small miner that shows why
   rewriting a blockchain's history is expensive.
